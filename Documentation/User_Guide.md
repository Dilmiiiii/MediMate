# MediMate User Guide

1. **Launch:** Read three onboarding cards or Skip. The first launch includes fictional sample medicine data for demonstration.
2. **Add a medicine:** Home → Add Medicine. Enter the name, type, prescribed dosage and schedule. For specific days, select weekdays; for Every X hours choose the interval. Enter inventory and threshold, then Save Medication.
3. **Scan a label:** Home → Scan Label. Select Gallery, Capture Image on a physical iPhone, or **Use Bundled Sample Label** in Simulator. Tap Extract Text. Review/correct every field, then Confirm & Continue. Enter any missing dosage/schedule data and Save.
4. **Respond to a dose:** Tap any dose in Home or History. Select Mark as Taken, Remind Me Later or Skip This Dose. Taken reduces tracked stock. Repeating Taken on an already taken event has no further stock effect.
5. **Review:** History lets you move between months, pick a day and filter the displayed period. Insights shows due/taken statistics and a chart; future doses are not included in adherence calculations.
6. **Manage inventory:** Home → Inventory or low-stock alert. Choose Update Stock, add purchased units and set alert threshold. Review inventory history.
7. **Edit medicines:** Medicines tab → search/filter/sort, swipe or long-press a card, edit its schedule, pause/resume reminders, or delete after confirmation.
8. **Manage profile:** Profile → Edit Profile. Enter optional emergency contact and self-reported allergies. Do not enter real clinical data during student demonstrations.
9. **Change settings:** Profile → App Settings. Control reminders/refill warnings, snooze length, theme, larger text; ask for notification permission. Export CSV or delete all local data if desired.
10. **Privacy and safety:** Data is stored locally. Scanned labels can be inaccurate. For medication dosing questions or emergencies, contact your healthcare professional/emergency service. This app does not give medical advice.

**Simulator note:** A real iPhone camera is unavailable in standard iOS simulator. A locally bundled sample label exercises the actual Apple Vision text recognition pipeline.
